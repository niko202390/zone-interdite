# Zone Interdite

![Zone Interdite](docs/images/title.png)

A slow, hard, quasi-horror stealth/survival FPS set in occupied Brittany, winter 1943–44. You play a French-Canadian SOE agent who has to steal German Enigma material and escape to the coast.

- Engine: Godot 4.7, with the project in `game/`. Builds target Windows desktop.
- Every asset is generated from scratch by the scripts in `tools/`. See `docs/ASSET_PIPELINE.md`.
- Design: `docs/DESIGN.md`. Historical research: `docs/research/`.

Binary assets are stored with Git LFS, so run `git lfs install` before you clone.

**Playing:** download the latest full build from [Releases](https://github.com/niko202390/zone-interdite/releases). It updates itself with small patches from the title screen. See `docs/RELEASING.md`.
